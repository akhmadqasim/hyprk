# Linux icon name or app id  ->  macOS app icon (themes/icons/apps/<Name>-512.png)
#
# The one source of truth for which macOS icon stands for a Linux app:
#   - build-apple-theme.sh builds the hyprk-apple icon theme layer from it,
#   - tools/gen-map.mjs generates apple-map.js from it (shell/services/macicons.js and
#     finder/qml/lib/macicons.js are symlinks to that file), so the Dock, Launchpad, Spotlight,
#     notifications and the Finder Applications view all use the same table.
# Lookup (apple-map.js): the whole name lowercased (".desktop" dropped), then its last dot segment
# against the last dot segment of every key below (org.gnome.Calculator also matches Calculator).
# The first line for a segment wins. A name starting with @ is an icon from themes/icons/system
# (Trash, folders). Only apps with an obvious macOS counterpart among the extracted icons are listed.
# Apple artwork is tracked on purpose: this repo is private (CONTRIBUTING.md, "Assets").
# After editing: node themes/icons/tools/gen-map.mjs && themes/icons/build-apple-theme.sh
